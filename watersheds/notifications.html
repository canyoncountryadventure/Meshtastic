Heltec V9 · Missing-AUTO fallback

Every station starts with automatic DM rescue OFF. Normal sensor broadcasts always continue. When you enable a station here, Heltec will send a fallback sensor DM only if its own automatic reading has been missing for the interval you choose. This site builds the command for you; send it as a Meshtastic direct message to Heltec.

Send this direct message to Heltec

A command only changes the Heltec's fallback schedule after it actually receives and acknowledges the DM.

To review which stations are enabled, DM AUTO DM STATUS. To disable all fallback polling, DM AUTO DM OFF. A one-time manual request is still available using POLL PACK CREEK WATER or POLL MILL CREEK READ. These commands never change the field station's own automatic telemetry interval.
